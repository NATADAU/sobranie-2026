# Собрание к началу учебного года

Лендинг внутреннего собрания РБОО «Центр лечебной педагогики».  
31 августа, 11:00, Москва, ул. Профсоюзная, 136, корпус 5.

Сайт живёт в этом репозитории и не зависит от poehali.dev.

## Как открыть на компьютере

Нужны [Node.js](https://nodejs.org/) (LTS) и эта папка.

```bash
npm install
npm run dev
```

В терминале появится адрес, обычно `http://localhost:5173/sobranie-2026/`. Откройте его в браузере.

Собрать файлы для публикации:

```bash
npm run build
```

Готовый сайт окажется в папке `dist`.

Страница на GitHub Pages: `https://natadau.github.io/sobranie-2026/`
